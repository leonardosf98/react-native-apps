# App 15 — Vagas de TI

Lista vagas de emprego de TI com **FlatList**: a primeira tela mostra só o título de cada vaga e o botão **Saiba mais**, que abre uma segunda tela (**Stack Navigator**) com empresa, salário, modalidade, local, descrição, requisitos e contato.

## Como rodar

```bash
cd app-15-vagas-ti-flatlist
npm install
npx expo start
```
