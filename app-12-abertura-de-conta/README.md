# App 12 — Abertura de Conta

Formulário de abertura de conta bancária em **2 telas com Stack Navigator**: a primeira coleta nome, idade, sexo, escolaridade, limite desejado e nacionalidade (com validação) e a segunda mostra o resumo da conta aberta, recebendo os dados por parâmetros da rota.

## Como rodar

```bash
cd app-12-abertura-de-conta
npm install
npx expo start
```
