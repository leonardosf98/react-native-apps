# App 04 — Álcool ou gasolina

Compara o litro do etanol com o da gasolina: etanol ÷ gasolina. Abaixo de **0,70**, etanol; acima, gasolina. Expo SDK 57.

Preços em real com **3 casas** (padrão de bomba no Brasil) e máscara `R$ 0,000`.

## Como rodar

```bash
cd app-04-alcool-ou-gasolina
npm install
npx expo start
```

Web: `npm run web`.

## Cores

Verde e amarelo de posto, sem marca no app.
