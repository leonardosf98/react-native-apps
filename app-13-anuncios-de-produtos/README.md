# App 13 — Anúncios de Produtos

Lista de anúncios em uma **ScrollView** com foto, título e botão **Ver detalhes**. O botão abre, via **Stack Navigator**, uma segunda tela com a foto e as informações do produto (preço, descrição, condição, vendedor e cidade).

## Como rodar

```bash
cd app-13-anuncios-de-produtos
npm install
npx expo start
```
