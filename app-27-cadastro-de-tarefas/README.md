# App 27 — Cadastro de Tarefas

Lista, inclui, altera, conclui e exclui tarefas usando a API `https://tarefa-backend.onrender.com/tasks`. O servidor fica no Render e pode levar até um minuto para acordar na primeira chamada.

## Como rodar

```bash
cd app-27-cadastro-de-tarefas
npm install
npx expo start
```
