# App 24 — Perfil de Devs

Busca um usuário do GitHub pelo login usando a API pública `https://api.github.com/users/<login>` e mostra avatar, bio, empresa, local, blog, repositórios, seguidores, seguindo e data de criação da conta, com botão para abrir o perfil.

## Como rodar

```bash
cd app-24-perfil-de-devs
npm install
npx expo start
```
