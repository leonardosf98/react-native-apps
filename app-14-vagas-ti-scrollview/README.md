# App 14 — Vagas de TI (ScrollView)

Lista vagas de emprego de TI com **ScrollView** e **Stack Navigator**. A primeira tela mostra só o título de cada vaga e o botão "Saiba mais", que abre uma segunda tela com todos os detalhes da vaga.

## Como rodar

```bash
cd app-14-vagas-ti-scrollview
npm install
npx expo start
```
