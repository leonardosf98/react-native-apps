# App 20 — Frase com Preferências

Exibe uma frase personalizável com preferências de tema claro/escuro, tamanho da fonte, cor de destaque, alinhamento e estilo. A frase e as preferências são salvas com **AsyncStorage** e restauradas ao abrir o app.

## Como rodar

```bash
cd app-20-frase-preferencias
npm install
npx expo start
```
