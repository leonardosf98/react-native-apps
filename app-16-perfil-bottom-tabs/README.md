# App 16 — Meu Perfil com Bottom Tab Bar

Perfil profissional do Leonardo Souza dividido em abas inferiores (React Navigation Bottom Tabs + ícones Ionicons): **Pessoal**, **Formação**, **Experiência** e **Projetos/Habilidades**. Os dados ficam na constante `PROFILE_EDITAVEL` em `profile.js`.

## Como rodar

```bash
cd app-16-perfil-bottom-tabs
npm install
npx expo start
```
