# App 23 — Consulta de CEP

Busca o endereço de um CEP usando a API pública do [ViaCEP](https://viacep.com.br) (`https://viacep.com.br/ws/<cep>/json/`) e mostra logradouro, complemento, bairro, cidade/UF, DDD e código IBGE.

## Como rodar

```bash
cd app-23-consulta-cep
npm install
npx expo start
```
