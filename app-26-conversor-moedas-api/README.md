# App 26 — Conversor de Moedas

Converte um valor em Real para Dólar, Euro ou Bitcoin usando a cotação atual (`ask`) da [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas): **resultado = valor em Real / cotação**.

## Como rodar

```bash
cd app-26-conversor-moedas-api
npm install
npx expo start
```
